# Галерея SKLO.STUDIO

Все 15 предоставленных роликов включены в раздел «Наші результати». Сначала видны 6 карточек, затем посетитель может показать следующие или выбрать «Процес» / «Результат».

На странице нет автоматически загружаемых видеоплееров. Карточки содержат WebP-кадры с отложенной загрузкой. Видео создаётся и начинает загружаться только после нажатия. В окне работает один плеер; при закрытии звук и воспроизведение останавливаются, источник удаляется. Можно закрыть кнопкой ×, Escape или нажатием вне окна. При отключённом JavaScript доступны все карточки и обычные ссылки на видео.

Видео подготовлены в MP4 (H.264, AAC), 24 кадра/с, с данными для начала воспроизведения в начале файла. Исходное разрешение 464×848 сохранено. Все видео вместе — примерно 30,7 МБ, все WebP-превью — примерно 364 КБ. Превью не являются фотографиями более высокого разрешения: они извлечены из присланных роликов.

## Как загрузить обновление

1. Распакуйте SKLO_STUDIO_gallery_update.zip.
2. Откройте ваш репозиторий sklostudio33 → main → Add file → Upload files.
3. Перетащите все файлы архива, кроме UPLOAD_README.txt, в корень рядом с package.json. Файлы HTML/CSS/JS/JSON/build.mjs должны заменить одноимённые. Видео и WebP загружаются туда же, без создания папок.
4. Сохраните все файлы одним Commit changes. Сам ZIP в GitHub загружать не нужно.
5. Дождитесь Ready нового коммита в Vercel. Обновите сайт и проверьте на телефоне: карточки, «Показати ще», фильтры, звук и закрытие плеера.

В архиве 38 файлов для загрузки плюс эта краткая инструкция. Настройки Supabase, Telegram, Google Sheets и переменные Vercel менять не требуется.

Если после предыдущего обновления вы самостоятельно меняли тексты, HTML, CSS или JavaScript, сохраните свои текущие файлы перед заменой и перенесите эти правки.

## Как менять галерею

results.json — список карточек в порядке показа. Например:

```json
{
  "title": "Нанесення клею",
  "description": "Підготовка скла перед встановленням.",
  "image": "work-13.webp",
  "video": "work-13.mp4",
  "category": "process",
  "width": 464,
  "height": 848,
  "duration": 32
}
```

- title и description — подписи на украинском языке.
- image — обязательное изображение. Допустимы work-*.jpg/jpeg/png/webp/avif.
- video — необязательный ролик work-*.mp4. Если убрать это поле, карточка открывает фотографию.
- category — process или result.
- width и height — размеры исходного изображения, duration — длительность ролика в секундах.
- Чтобы переставить карточки, переставьте объекты в массиве. Чтобы скрыть работу, удалите её объект; файлы без ссылок в results.json не публикуются.

Загружайте новое изображение и видео вместе с results.json одним коммитом. Не вставляйте произвольные пути, ссылки и имена файлов с пробелами.

## Что проверено

Сборка и 12 тестов API/публикации проходят. Проверены безопасные имена файлов, отказ сборки при отсутствии указанного видео, экранирование подписей, отсутствие видео-элементов в начальной странице. В отдельной проверке состояния интерфейса проверены показ 6/12/15 карточек, фильтры, создание плеера только по нажатию, остановка и удаление источника после закрытия, возврат фокуса. Формат и длительность всех 15 MP4 проверены.

Визуальная проверка в настоящем браузере и воспроизведение на реальном телефоне в этой среде не выполнены; их нужно сделать после загрузки в Vercel.
