ВИЗУАЛЬНОЕ ОБНОВЛЕНИЕ SKLO.STUDIO

Добавлены: реальные кадры работ на первом экране и в блоке выездного сервиса, схемы скола, трещины и повреждения края.

1. Распакуйте архив.
2. Откройте GitHub → sklostudio33 → main → Add file → Upload files.
3. Загрузите все 7 файлов, кроме UPLOAD_README.txt, в корень рядом с package.json. Замените существующие файлы.
4. Commit changes. Дождитесь Ready в Vercel и обновите сайт.

Файлы studio-*.webp загружать обязательно: это фотографии основных блоков.
Сам ZIP загружать не нужно. Переменные Vercel, Supabase и Google Sheets менять не требуется.

Если вы ещё не загрузили галерею видео, можно вместо этого взять обновлённый SKLO_STUDIO_gallery_update.zip — в нём уже есть и галерея, и эти визуальные изменения.

Для следующих правок: заменяйте studio-hero.webp, studio-detail.webp, studio-mobile.webp файлами с теми же именами. Все подписи и схемы — в index.html.

Сборка и тесты прошли. Проверьте отображение на телефоне после публикации.
